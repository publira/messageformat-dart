# messageformat-dart

A pure-Dart implementation of [Unicode MessageFormat 2.0](https://www.unicode.org/reports/tr35/tr35-78/tr35-messageFormat.html), conformant to LDML 48.2.

| Package | Description |
|---|---|
| [`messageformat`](messageformat/) | The MessageFormat 2.0 parser and formatter. See its [README](messageformat/README.md). |

The repository is a [pub workspace](https://dart.dev/tools/pub/workspaces). [AGENTS.md](AGENTS.md) describes how to work in it.
